# NutriDaily (个人营养与晨练健康日志)

专为 30 岁、55kg 精瘦增肌、倒金字塔营养（早大午中晚小）、晨练力量运动与严格无麸质需求定制的现代化私密个人健康记录应用。

## 🌟 核心特性
- **专属 PIN 码锁屏**：默认 6 位专属密码（初始 `668899`，可随时修改），保障数据隐私。
- **睡前 1 键极速记录**：预置全套早大午中晚小食谱，5 秒完成今日打卡。
- **倒金字塔结构可视化**：实时计算早/中/晚三大餐能量占比。
- **无麸质安全标记**：肠胃反应监控与过敏原排查。
- **GitHub 私有云同步**：通过 GitHub Private Gist 实现多端自动加密漫游，换机不丢数据。
- **PWA 支持**：可在手机浏览器中“添加到主屏幕”，享受原生 App 体验。
